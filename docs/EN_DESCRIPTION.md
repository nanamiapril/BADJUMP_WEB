### 🤖 AI Voice Roast System
- **Real-time Voice Comments**: AI provides live voice commentary on your gameplay
- **Rich Content Library**: 100+刻薄 yet funny comments
- **Multiple Trigger Scenarios**: Jumping, falling, scoring, idle time, and more
- **Unique AI Personality**: Sarcastic, witty tone with plenty of attitude

### 🎮 Gameplay
- **Classic Jumping**: Use arrow keys or touch screen to control character
- **Platform Challenges**: Dodge moving platforms and jump as high as possible
- **Scoring System**: Earn points based on height reached
- **Responsive Design**: Supports both desktop and mobile devices

## 🎯 Controls

### Desktop
- ← → Arrow keys: Move left/right
- Spacebar or ↑ Arrow key: Jump
- Click screen: Jump

### Mobile
- Virtual D-pad: Move left/right
- Jump button: Jump
- Screen tap: Jump

## 🔊 Voice Features

The game uses Web Speech API for text-to-speech synthesis, providing real-time AI voice commentary.

### Voice Settings
- **Language**: English (en-US)
- **Speed**: 1.1x (slightly faster for more attitude)
- **Volume**: 100%
- **Voice Type**: Female (more sarcastic)

### Common Issues
1. **No Sound?**
   - Check if your browser supports Web Speech API
   - Ensure system volume is enabled
   - Try refreshing the page to reload the voice engine

2. **Voice Delay?**
   - First-time use requires voice resource loading
   - Network conditions may affect voice loading speed
