### 🤖 AI语音吐槽系统
- **实时语音评论**：AI会用语音对你的游戏表现进行实时吐槽
- **丰富的吐槽内容**：100+条刻薄但搞笑的评论
- **多种触发场景**：跳跃、掉落、得分、长时间不操作等
- **个性化AI人设**：刻薄、贱贱的语气，充满sarcasm

### 🎮 游戏玩法
- **经典跳跃**：使用方向键或屏幕控制角色跳跃
- **平台挑战**：躲避移动平台，尽可能跳得更高
- **得分系统**：根据高度获得分数
- **响应式设计**：支持桌面和移动设备

## 🎯 操作说明

### 桌面端
- ← → 方向键：左右移动
- 空格键 或 ↑ 方向键：跳跃
- 点击屏幕：跳跃

### 移动端
- 虚拟方向键：左右移动
- 跳跃按钮：跳跃
- 屏幕滑动：跳跃

## 🔊 语音功能

游戏使用Web Speech API进行语音合成，提供实时的AI语音吐槽。

### 语音设置
- **语言**：英语（en-US）
- **语速**：1.1x（稍快，显得更刻薄）
- **音量**：100%
- **语音类型**：女声（更有调侃感）

### 常见问题
1. **没有声音？**
   - 检查浏览器是否支持Web Speech API
   - 确保系统音量已开启
   - 尝试刷新页面重新加载语音引擎

2. **语音延迟？**
   - 首次使用时需要加载语音资源
   - 网络状况可能影响语音加载速度
